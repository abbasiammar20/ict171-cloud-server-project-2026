Simple Blog Hosted on Azure

This website is a multi-page blog project hosted on a Microsoft Azure virtual machine. It uses Ubuntu and Nginx to demonstrate manual cloud server deployment.

Project Overview

Cloud Platform

Hosted on Microsoft Azure using Infrastructure as a Service.

Server Stack

Ubuntu Linux is used with Nginx as the web server.

Purpose

The project demonstrates SSH access, server setup, file deployment, and basic website hosting.

Technologies Used

Microsoft Azure Ubuntu Nginx HTML CSS GitHub Shell Script
